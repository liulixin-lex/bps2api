# BPS2API 0.0.20

## 修复

- 修复 BPS 前输出可恢复流失败的代理健康反馈顺序：先报告失败，再释放租约，避免连续选择已失败出口。
- 本地账号 RPM 耗尽准确归类为网关路由容量限制，保留 HTTP 429 和 Retry-After；实际上游 429 仍单独记录。
- basispoints_request_timeout 正确记录为逻辑 HTTP 504，避免误记为 502。
- 健康审计正确识别冒号形式的 Recovered upstream error 记录，避免已恢复事件误算最终失败。
