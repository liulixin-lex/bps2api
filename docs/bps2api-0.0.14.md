# BPS2API 0.0.14

择优融合 ranxi2001/sub2api production 的账号、代理池、观察员、附件和诊断更新，同时保留本 fork 的严格 OpenAI OAuth BPS 路由、原始图片精度、工具源码、终态和有界资源策略。

## 多轮与错误处理

- 支持 `tool_choice=required`、指定客户端工具与 allowed_tools，校验实际交付的工具身份和并行约束。
- 区分 encrypted_content 与其他未知内容；默认明确拒绝密文，账号显式选择后可用不可用标记有损继续，不是解密。
- 输出前的模型权限 403 和 BPS 429 仅切换到相同实际模型的其他 BPS 账号，保留模型映射优先级，不静默改用原生通道。
- 处理失效 OAuth 凭据、Retry-After、取消与终态，避免取消后追加 502 或重复错误。撤销的凭据和上游权限仍须恢复有效授权。

## 升级注意

新增迁移 `252_user_observer_groups.sql`，为 users 添加有默认值的 JSONB 字段。升级前备份数据库。原生附件、内容省略和 403 自动管理策略按各自开关启用，不能假定升级会自动开启。

保留旧容器作为回滚目标及历史图片 URL 的所有者。前后端回归、构建、定向集成、竞态及源码回滚验证已通过；实际上线结果见开发历程中的发布记录。
